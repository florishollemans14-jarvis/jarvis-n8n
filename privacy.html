Privacy policy: Jarvis n8n

Last updated: 19 November 2026

Who uses this app

Jarvis n8n is a private automation used by one person, the owner of the connected Google account. It is not offered to anyone else.

What data it accesses

With the owner's permission, the app reads and labels messages in the owner's Gmail account and reads events in the owner's Google Calendar. It only accesses the account of the person who signed in.

How the data is used and stored

The data is processed by n8n running on the owner's own computer. It is used only to sort, label and summarise the owner's own mail and calendar for the owner. Nothing is stored on any server operated for this app.

Sharing

Google user data is not sold, not shared with third parties, not used for advertising and not used to train AI models.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions about this policy: open an issue in this site's GitHub repository.
